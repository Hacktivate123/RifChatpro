# RifChatPro

> **⚠️ Project Status: Beta Phase (v0.1.0)**
> This application is currently in its early experimental stage. We are actively working on it and will release updates as often as possible to add new features, improve performance, and enhance security. Our goal is to build a complete, secure, and highly reliable application. We appreciate your patience and feedback!

**RifChatPro** is a lightweight, secure, and real-time group chat application. It is designed to be self-hosted, giving you full control over your data without relying on third-party cloud providers.

## 🚀 Features

- **Real-time messaging:** Instant message delivery using Socket.io.
- **Self-hosted:** Your server, your data. No third-party tracking.
- **Secure:** Built with security in mind (Rate limiting, XSS protection).
- **Lightweight:** Fast and responsive UI.
- **Open Source:** 100% free and open-source. You can modify and distribute it as you wish.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, Vanilla JavaScript.
- **Backend:** Node.js, Express.js.
- **Real-time Engine:** Socket.io.
- **Database:** SQLite (via `better-sqlite3`).
